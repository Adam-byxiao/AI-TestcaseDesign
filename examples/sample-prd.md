# PRD：示例商城（sample-mall）v0.1

> 本示例 PRD 用于 prd2tc 的快速体验与离线自测，结构遵循推荐章节（概述/角色/功能需求/业务规则/非功能需求）。

## 1. 概述

示例商城是一个极简电商演示应用，覆盖注册登录、商品浏览、购物车与结算下单。用于演示「PRD → 测试方案 → 测试用例」全流程。

## 2. 角色

| 角色 | 说明 |
| --- | --- |
| 游客 | 未登录可浏览商品与加购；结算需登录 |
| 注册用户 | 可结算下单、查看订单 |

## 3. 功能需求

### 3.1 账号（AUTH）

| 编号 | 需求点 | 验收标准 |
| --- | --- | --- |
| REQ-AUTH-001 | 手机号+密码注册 | 合法手机号且密码 ≥6 位注册成功并自动登录；否则明确报错 |
| REQ-AUTH-002 | 手机号+密码登录 | 正确凭据登录成功跳转首页；错误密码明确提示 |

### 3.2 商品（PROD）

| 编号 | 需求点 | 验收标准 |
| --- | --- | --- |
| REQ-PROD-001 | 商品列表与详情 | 列表展示名称/价格；详情页价格与库存正确 |
| REQ-PROD-002 | 加入购物车 | 选择商品规格后可加入购物车，数量可修改 |

### 3.3 结算（CHECKOUT）

| 编号 | 需求点 | 验收标准 |
| --- | --- | --- |
| REQ-CHECKOUT-001 | 金额计算 | 应付 = 小计 + 运费 − 优惠券抵扣，金额保留 2 位小数 |
| REQ-CHECKOUT-002 | 提交订单 | 提交成功跳转订单成功页并展示订单号 |

## 4. 业务规则

- BR-1 手机号须为 11 位中国大陆手机号；密码 ≥ 6 位。
- BR-2 优惠券满 100 减 20；合计 ≥ 100 可用，否则不可用。
- BR-3 标准配送免运费，次日达运费 10 元。

## 5. 非功能需求

| 编号 | 类别 | 要求 |
| --- | --- | --- |
| REQ-NFR-001 | 性能 | 列表页首屏 < 2s |
| REQ-NFR-002 | 兼容 | Chrome / Firefox / WebKit 三浏览器核心链路通过 |

- 账号：normal 用户 13800138000 / 123456。
