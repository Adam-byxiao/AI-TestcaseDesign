## 9. 评测方法与证据

全部结论来自**逐条枚举**，非关键词计数：

- **契约合规**：340 个标注逐条按「种类 + 值」独立复算（不依赖门禁自身的结论）
- **覆盖度**：31 条需求逐条对照追溯矩阵；PRD 五个主章节逐节核验
- **重复性**：4 组同签名用例逐组人工判定（区分「合法等价类」与「真重复」）
- **可读性**：导出产物逐项检索机器标记；无断言用例逐条枚举
- **准确度**：19 个专用术语全产物检索；路由逐条比对契约页面键

数据脚本：`$TEMP/eval_v3.py`、`eval_prio.py`、`compare_prio.py`、`verify_nl_real.py`

### 方法论教训（累计）

1. **「门禁报告 0 问题」≠「产物合规」** —— 必须独立复核门禁自身能力（v2 的 19 处越界因此被发现）。
2. **同步骤签名 ≠ 重复** —— 等价类/边界值本就「同流程不同数据」，判定需结合设计意图。
3. **对比评测须确认基准一致** —— v1 用的是 AI 扩写版 PRD，其「提升」部分来自输入变干净。
4. **接线必须单独测** —— 纯函数测试全绿，不代表它被调用过（本项目已因此漏报 3 次）。
